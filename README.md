# IoT Sensor Data Monitoring

## Overview

This project simulates IoT sensor data monitoring and detects anomalies in temperature and vibration readings using Machine Learning.

## Features

* Generates simulated IoT sensor data.
* Monitors:

  * Temperature readings
  * Vibration readings
* Detects anomalies using Isolation Forest.
* Visualizes sensor data with graphs.
* Displays anomaly alerts.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Installation

```bash
pip install numpy pandas matplotlib scikit-learn
```

## Usage

Run the script:

```bash
python iot_sensor_data_monitoring_.py
```

## Output

* Sensor monitoring dashboard.
* Temperature anomaly detection graph.
* Vibration anomaly detection graph.
* Alert messages for detected anomalies.

## Project Workflow

1. Generate sensor readings.
2. Inject abnormal values.
3. Visualize sensor data.
4. Detect anomalies using Isolation Forest.
5. Display alerts and anomaly plots.
